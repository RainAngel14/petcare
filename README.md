# Pet Care
## Acerca de
Aplicación web que permita a los propietarios de mascotas encontrar y gestionar servicios relacionados con el cuidado de sus animales de compañía.

## Arquitectura
El proyecto se encuentra realizado en HTML y CSS vanilla con el objetivo de validar como maquetado del prototipo en [Figma](https://www.figma.com/design/jhJBHaHnL6MVpbrFzQ4aZO/Untitled?node-id=26-1917&p=f&t=clI8h4zgtEs4h473-0)
- Assets: Aquí estará cualquier objeto tipo contenido como imágenes en sus formatos debidos
    - Images: Carpeta de imágenes
- Pages: Está carpeta es la responsable de contener las páginas en .html
- Styles: Responsable de tener todos los archivos de hojas de estilo en .css
